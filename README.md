# 録音して、フーリエ解析

マイクで録音した音（または音声ファイル）を、フーリエ解析して、どんな高さの音がどれくらい混ざっているかをグラフにするウェブアプリです。

使う: https://onasu-susu.github.io/fourier-analyzer/

- 波形・スペクトル（FFT）・スペクトログラム・基音（YIN）・音名を表示
- 基音の周期で、フーリエ級数の係数 a₀・aₖ・bₖ を計算し、[フーリエ級数で音をつくる](https://onasu-susu.github.io/fourier/) に渡して再合成して聴ける
- 録音も計算も、ページの中だけで行います（どこにも送りません）

## ファイル

- `index.html` … 画面
- `style.css` … 見た目
- `dsp.js` … 計算（FFT・ピーク探し・基音の推定・音名・係数・WAV への書き出し）。画面と関係なく単独でテストできます
- `app.js` … 録音（AudioWorklet）・グラフの描画・操作
